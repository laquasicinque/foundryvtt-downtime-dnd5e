# Requirements
- Foundry VTT v14
- dnd5e 6.0 or later

# Sheets
- The core dnd5e character and NPC sheets
- Tidy5e Sheet

Other sheets that build on the core dnd5e sheets may work, but aren't tested.

# Other modules
- Dice So Nice: rolls made through a downtime method animate as usual.
- Modules that add dnd5e activity types can register how their activities roll for tool checks (see [API → Activity roll adapters](./API.md#activity-roll-adapters)).
